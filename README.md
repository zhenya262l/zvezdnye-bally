# Звёздные баллы

Веб-приложение для iPhone и Android, которое переносит в телефон бумажный «Дневник звёздных баллов». Ребёнок отмечает дела, родитель подтверждает, баллы меняются на радости.

Приложение ставится на экран «Домой» из Safari и работает как обычное приложение. App Store не нужен.

## Что готово

Этап 1 — каркас:

- Вход родителя по коду из письма.
- Создание семьи и профилей детей с датой рождения, возраст считается сам.
- Подключение телефона ребёнка по 6-значному коду с телефона родителя.
- Отвязка телефона, выход, удаление семьи со всеми данными.
- Вкладки родителя и ребёнка, иконки, установка на экран «Домой».

## Как устроено

| Часть | Где |
| --- | --- |
| Экраны (Expo Router) | `src/app` |
| Все тексты интерфейса | `src/strings.ru.ts` |
| Связь с базой | `src/lib/api.ts`, `src/lib/supabase.ts` |
| Пуши и Face ID (общий интерфейс) | `src/platform` |
| База данных и правила доступа | `supabase/migrations` |
| Настройка Supabase | `supabase/SETUP.md` |
| Service worker | `sw/sw.ts` |
| Публикация на GitHub Pages | `.github/workflows/deploy.yml` |
| Решения и их причины | `DECISIONS.md` |

## Команды для разработчика

```bash
npm ci                    # установить библиотеки
npm run typecheck         # проверка типов
npm run devstack          # локальный стенд: Postgres + Supabase Auth + PostgREST (Linux, не от root)
npm run test:db           # проверки базы и правил доступа на стенде
bash scripts/build-local.sh && node devstack/serve-dist.mjs &   # сборка для стенда
npm run test:e2e          # сквозная проверка в Chromium в размере iPhone
```

Сборку и публикацию для телефонов делает GitHub Actions при каждом изменении ветки `main`. Файл автосборки `.github/workflows/deploy.yml` хранится в репозитории на GitHub. Новую работу начинайте с копии из GitHub, там всегда полная версия.
